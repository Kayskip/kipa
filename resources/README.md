# Resources

Working files for research, split so new material has a place to land. The ingested synthesis stays at the repo root in [whakapapa.md](../whakapapa.md). These folders do not replace it.

- [people](people/README.md): one file per person we have a record for.
- [whakapapa](whakapapa/README.md): the lines those people sit on.

A statement is tagged the same way as the root notes:

- **Stated:** said in the conversation ingested on 11 November 2026.
- **Sourced:** written on a named public page.
- **Unlinked:** a likely connection that no source yet joins with a parent name.
